Форма демонстрационная: заявки не отправляются. Возраст, опыт, цена, обещания результата и контакты требуют подтверждения перед основным запуском. Просмотр не разрешает основную публикацию, слияние или подключение реальной отправки.

## Повторяемое обновление

1. Получить отдельную согласованную задачу; проверить актуальные источник, branch/commit и состав изменений.
2. Проверить только файлы сайта, их размеры/SHA256 и отсутствие посторонних секретов/частных метаданных.
3. Создать новый каталог `snapshots/<полный-source-commit-SHA>/`. Старые снимки не перезаписывать. Для существующего пути сначала сверить манифест и байты.
4. Сохранить исходные 17 файлов побайтно и с прежними относительными именами; добавить `snapshot.json` со ссылкой на источник и списком файлов, размеров и SHA256.
5. Обновить корневые `index.html` и `previews.json`, сохраняя прежние записи. Не переносить приватную Git-историю, другие проекты, локальные отчёты, конфиги, ключи или CNAME.
6. Размещать только эту площадку: GitHub Pages, main / (root), стандартный HTTPS-адрес без custom domain/DNS. Дождаться успешного deployment, проверить HTTPS и хеши всех файлов, относительные пути и нужные функции в браузере.
7. Вернуть владельцу ссылку точного снимка и доказательства проверки. Основной сайт и домен требуют отдельного согласования.

.nojekyll должен оставаться в корне. Noindex — рекомендация поисковым роботам, а не ограничение доступа: предпросмотр публичный.
